# Sugar MOD

*Note: AI was used in parts of this mod's development.*

**This is the "sweetest" Minecraft mod ever!** *(Self-proclaimed)*

## Features

- **Sugar Cube:** A big sugar cube. Unfortunately, you can't eat it.
- **Konpeito:** A traditional Japanese sugar confection. Can be eaten quickly!
- **Caramel:** Made by roasting sugar. Might overlap with other mods, though, lol.

And even more ~~strange~~ other features!

## For Developers

**Looking for port maintainers!**

I'd love to see Sugar MOD available for other Minecraft versions and mod loaders, especially NeoForge 1.21.1.

I'm the original author, and I intend to focus exclusively on the Fabric 26.3 version of this mod. Support for other Minecraft versions and mod loaders is welcome through independent community-maintained forks.

- Forking and independent maintenance are welcome.
- You can publish your own port.
- The project is licensed under MIT.
- No need to ask me for permission for modifications and redistribution permitted by the MIT License.

**About the build system:**

The original project uses my own custom build tool, which is currently not publicly available.

However, I intend to keep the source code compatible with standard Gradle-based mod development workflows where possible.

You are free to use your own Gradle project and build setup for the port. There is absolutely no requirement to use my custom build tool.

I'd prefer independent, version-specific maintenance rather than maintaining multiple Minecraft versions and mod loaders myself.

**Interested in porting Sugar MOD? Feel free to fork the repository!**
