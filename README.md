# Sugar Mod

*Note: AI was used in parts of this mod's development.*

**This is the "sweetest" Minecraft mod ever!** *(Self-proclaimed)*

## Features

- **Sugar Cube:** A big sugar cube. Unfortunately, you can't eat it.
- **Konpeito:** A traditional Japanese sugar confection. Can be eaten quickly!
- **Caramel:** Made by roasting sugar. Might overlap with other mods, though, lol.

And even more ~~weird~~ features!

## Issue Policy
